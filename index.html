Our Project: CareerLens

Project Overview

CareerLens is an interactive, front-end based web application that helps students explore potential career paths in an informed and engaging way. The system allows users to browse various fields such as STEM, business, arts, and more, while providing essential information including required skills, average salary ranges, and growth opportunities.

Key Features

Career Exploration

Browse various career fields with detailed information

Skill Roadmaps

Personalized learning paths for different careers

Resume Builder

Templates and tips for creating effective resumes

Favorites

Save and organize preferred career options

Technology Stack

HTML5 CSS3 JavaScript Node.js Express.js MongoDB React
